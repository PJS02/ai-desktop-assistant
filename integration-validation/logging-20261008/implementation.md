# 로그 누락 보완 결과

2026-10-08에 승인된 범위를 구현했습니다. 앱을 다시 실행하면 새 로그 수집기가 적용됩니다.

로그창은 행별 요약을 표시하며, 행을 선택하면 아래 상세 영역에서 요청·응답 전문을 확인할 수 있습니다. 검색은 메시지, 추적 ID, 상세 정보 전체에 적용됩니다.

| 항목 | 중요도 | 구현 내용 |

| 공통 수집·분류 | 최상 | 이벤트명, 수준, 명시적 분류, 시간, 세션, 프로세스, 스레드, 추적 ID, 상세 데이터 |
| 대화 입력·대기 | 최상 | 텍스트/음성 입력 접수·거절, 대기 원인, 처리 시작과 대기 시간 |
| Gemini 전달 내용 | 최상 | 실제 최종 프롬프트, 사용한 대화 기록, 모델과 HTTP 요청 본문 |

입력, Gemini 요청·응답, 정규화, 말풍선, TTS는 같은 `trace_id`로 검색할 수 있습니다. 음성은 STT 결과의 ID를 대화 입력까지 이어 전달하며, 설정과 게임에는 각 작업·세션 ID를 사용합니다. API 키와 인증 정보는 로그 구독자와 파일 저장에 전달하기 전에 제거합니다.

메모리는 최근 5,000건을 보관합니다. 프로젝트의 `logs/app.jsonl`은 비동기로 기록하며, 10MB 단위로 회전하고 백업 5개를 보관합니다. 화면에는 메모리 보관 초과, 파일 대기열 누락, 파일 오류 상태를 표시합니다. 로그 파일은 Git 추적에서 제외했습니다.

반복되는 프레임 정보는 의미 있는 상태 변화와 반복 횟수로 집계합니다. 기존 인식 임계값, 대화 대기, 모델 선택, 게임·물리 동작을 유지했으며, 전송 재시도나 새 ACK 프로토콜은 추가하지 않았습니다. 기존 전송 실패·폐기 동작을 로그로 드러냈습니다.

## 검증

- 최종 전체 회귀 테스트: **696개 통과**, 40.35초. `final-suite.xml`에 결과를 저장했습니다.
- 로컬 TCP 송수신, 실제 가짜 Python/Node 자식 프로세스, Windows fd·표준 핸들 출력, 분할된 한국어, 파일 회전·기록 실패·대기열 초과, 상세 표시·검색·보관, 종료 시 잔여 기록을 검증했습니다.
- Gemini와 Google STT 응답, 음성 합성·장치 상태, 카메라·설정 실패는 가짜 제공자와 장치 객체로 검증했습니다.
- 실제 Gemini/Google 요청, 실제 카메라·마이크·오디오 출력과 전체 앱의 장치 연결 실행은 하지 않았습니다. 모델 다운로드도 실행하지 않았습니다.
