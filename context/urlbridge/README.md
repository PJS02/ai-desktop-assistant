# URL Bridge (Chrome Extension)

## What it does
- Sends the active tab URL to a localhost HTTP receiver.

## Install (Chrome)
1. Open Chrome Extensions page.
2. Enable Developer Mode.
3. Load unpacked and select this folder.
4. Keep the extension enabled.

## Local HTTP Receiver
1. Run the Python classifier which starts the local server on http://127.0.0.1:8765.
2. Switch tabs or change URLs to send updates.
