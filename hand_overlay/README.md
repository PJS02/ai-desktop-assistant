# 본프로젝트 바탕화면 손 표시

프로젝트의 기존 카메라/Holistic 인식 결과를 재사용하여 손의 21개 점과 연결선만 작은 투명 창에 표시합니다. 별도 카메라나 MediaPipe 인스턴스를 추가하지 않습니다.

본프로젝트를 다시 실행한 뒤 **설정 → 사용자 인식 → 바탕화면에 손 표시**를 켜고 적용하세요. 카메라 선택은 기존 사용자 인식 설정을 공유합니다. 독립 실험에서 확인한 장치는 **카메라 2 / DirectShow**이며, 저장된 다른 장치 설정을 자동으로 덮어쓰지 않습니다.

- **손 크기:** 50–200%, 기본 100%. 이동 범위와 독립적으로 적용됩니다.
- **카메라 중앙 이동 범위:** 30–100%, 기본 70%. 70%는 영상의 중앙 가로·세로 70%를 화면 전체에 대응시킵니다. 손바닥 중심이 영역을 벗어나면 위치는 화면 가장자리에서 유지됩니다. 손 모양과 손 크기는 이 비율로 확대되지 않습니다.
- **표시할 손 수:** 기본 한 손, 선택 시 두 손. 기존 손 흔들기/가위바위보 인식은 양손의 원본 좌표를 계속 사용합니다.
- **움직임 보정:** 중복/이상 좌표 억제와 부드러운 이동을 적용합니다.

설정은 기존 사용자 `config.json`의 `hand_overlay` 항목에 저장하고 실행 중 즉시 적용합니다. 초기 상태는 손 표시 꺼짐이며, 켠 상태로 저장하면 다음 실행에 복원합니다. 카메라 중단·연결 끊김·오래된 좌표·프로그램 종료 시 손을 숨깁니다. 손 창은 클릭을 통과시키고 캐릭터의 발판 스캔에서 제외합니다.

## 내부 흐름

`HolisticGuiApp`이 손 표시 구독 명령을 받으면 원본 손 좌표를 별도 `hand_landmarks` 메시지로 보냅니다. 기존 TCP 연결에서 음성/제스처 이벤트의 FIFO와 손 좌표의 최신 값 하나를 분리합니다. `QtPerceptionReceiver`도 손 프레임을 Qt 이벤트에 쌓지 않고 최신 값 하나만 보관합니다. `HandOverlayController`가 33ms 타이머로 읽고 표시용 보정과 범위 매핑을 적용합니다. 화면은 Qt의 주 모니터 전체 영역을 사용합니다.

카메라 영상이나 매 프레임 좌표를 이 표시 경로에서 저장하지 않습니다. 실험 폴더 `hand_landmark_lab`는 같은 모델·렌더러를 공유하면서 독립 실행을 유지합니다.

범위를 줄이면 같은 카메라 위치 변화가 화면에서는 더 크게 나타납니다. 이 설정은 카메라 경계로 이동할 필요를 줄이는 기능이며, 인식 실패 자체를 복구하지는 않습니다. 실제 손의 튐·반응 지연은 통합 실행에서 별도로 확인해야 합니다. 캐릭터와의 접촉 동작은 후속 단계입니다.
