# AI Desktop Assistant (Prototype)

Python + PyQt 기반 데스크탑 캐릭터 예제 프로젝트

## 실행 방법

1. Python 설치 (3.10+ 권장)

2. 라이브러리 설치

pip install -r requirements.txt

3. API 키 설정

템플릿을 복사해 실제 설정 파일을 만드세요.

context/config/gemini_config.template.json -> context/config/gemini_config.json
context/config/igdb_config.template.json -> context/config/igdb_config.json

gemini_config.json 예시:

{
	"api_key": "YOUR_KEY",
	"model": "gemma-3-4b-it"
}

igdb_config.json 예시:

{
	"client_id": "YOUR_ID",
	"client_secret": "YOUR_SECRET"
}

4. 실행

python main.py

## 기능

- 화면 위 캐릭터 표시
- 클릭 반응
- 감정 애니메이션
- **캐릭터 대화 시스템** (NEW!)
  - 텍스트·최종 음성인식을 같은 AI 대화 경로로 처리
  - 기존형·둥근 말풍선형·간결한 자막형 선택
  - 나레이션 박스 UI
  - 순차 대화 큐 시스템
  - 다양한 대사 템플릿
- 캐릭터 위 가위바위보 카운트다운·선택·승패 표시
- 별도 점프 모션과 경과시간 기반 중력·창 착지

## 로컬 음성 읽기 (TTS)

AI 답변을 Supertonic 3 모델로 기기에서 합성해 읽습니다. 별도 TTS API 요금은 없습니다.
처음 음성을 사용할 때 모델 파일 약 400MB를 다운로드하며, 이후 합성은 인터넷 없이 동작합니다.
캐릭터를 우클릭해 **설정 → 음성**에서 **AI 답변 음성으로 읽기**를 켜거나 끄고, **목소리**에서
Supertonic 3의 기본 목소리 F1–F5, M1–M5를 고를 수 있습니다. 처음에는 F1로
음성 읽기가 켜져 있으며 선택은 저장됩니다. 모델은 OpenRAIL-M 라이선스를 따릅니다.

## 통합 설정

앱은 저장된 설정으로 바로 시작합니다. 캐릭터를 우클릭해 **설정**을 열면
캐릭터 활동 범위·성격, 음성 읽기·목소리, 카메라·마이크·STT·감정 인식,
Gemini API 키·모델을 한 창에서 변경할 수 있습니다.
캐릭터 탭에서 **크기(50–200%)**, **이동 속도(20–400px/초)**,
**점프 높이(20–500px)**를 슬라이더나 숫자로 조절할 수 있습니다.
크기 변경은 몸체 비율과 클릭 영역을 함께 바꾸고, 서 있는 표면에서의 아래쪽 위치를 유지합니다.
잡기와 낙하 동작에서도 설정한 배율을 유지합니다.
걷기와 공 따라가기는 같은 설정 속도를 사용하며, 이동 거리가 길면 이동 시간이 길어집니다.
랜덤 이동 폭은 감정별 기본 폭에 **(캐릭터 크기 비율 + 추가 이동 폭 비율)**을 적용합니다.
**추가 이동 폭 비율(-200–200%)**의 기본값은 0%이며, 크기 200%에 추가 +50%이면 기본 폭의 250%로 움직입니다.
최종 비율은 0% 이상으로 제한하며, 화면 경계 안에서 이동합니다. 추가 비율 변경은 다음 랜덤 이동부터 적용됩니다.
점프 높이는 출발 위치에서 올라가는 거리이며 화면 상단까지의 공간으로 제한됩니다.
**히트박스·인식한 창 표시**로 캐릭터 표시 영역, 겹치는 창 영역과 인식한 창 이름을 켜고 끌 수 있습니다.
캐릭터 표시 박스는 투명 여백을 제외한 몸체를 따라가며, 동반 캐릭터와 감정 효과는 포함하지 않습니다.
이 선택은 저장되며 리깅·스프라이트 렌더러 모두에 적용됩니다.
**적용**은 저장 후 창을 유지하고, **저장 후 닫기**는 적용 성공 후 닫습니다.
**닫기**는 아직 적용하지 않은 변경을 버립니다.

카메라는 실행 중이면 새 장치로 재연결하고, 마이크·STT 옵션 변경은 실행 중인
음성 인식을 다시 시작합니다. 중지된 장치는 다음 시작부터 새 설정을 사용합니다.
**장치 새로고침**으로 현재 인식 프로세스의 장치 목록을 갱신할 수 있습니다.
AI 설정은 두 기존 Gemini 설정 파일에 함께 저장하며 이후 요청부터 적용됩니다.
인식 콘솔과 감정 판단 근거·로그창은 우클릭 메뉴에서 계속 열 수 있습니다.

통합 설정의 **직접 조작** 탭에서 왼쪽·정면·오른쪽 보기, 좌우 이동,
제자리·좌우 점프, 정지, 인사·생각·잠자기, 기본 위치 복귀를 즉시 실행할 수 있습니다.
속도와 점프 높이는 현재 적용된 설정값을 사용합니다. 좌우 이동은 화면 경계에서 멈추며,
방향 점프는 착지하면 좌우 이동을 끝냅니다. 공중에서 정지하면 좌우 이동만 멈추고 자연스럽게 착지합니다.
인사·생각·잠자기는 공중·착지 동작이 끝나면 실행합니다.
기본 위치 복귀는 앱을 시작한 가로 위치의 바닥으로 이동합니다.
직접 조작 중에는 자동 이동·점프·공 따라가기·카메라 인사를 멈춥니다.
설정창을 닫아도 직접 조작 상태는 유지되며 **자동 행동 재개**로 해제합니다.
이 상태는 설정 파일에 저장하지 않으며 앱을 다시 실행하면 자동 행동으로 시작합니다.
인사·생각·잠자기 이미지가 없는 PNG 렌더러에서는 해당 동작을 실행할 수 없다는 안내를 표시합니다.
직접 조작 버튼 아래의 **보이는 감정 설정**에서 감정별 버튼을 누르면 즉시 표정을 고정합니다.
선택한 감정 버튼을 강조 표시하며 **실제 감정 따르기** 버튼으로 해제할 수 있습니다.
실제 감정 좌표·판단·영향 기록과 자동 행동은 계속 원래 감정을 사용합니다.
설정창을 닫아도 표정 고정은 유지되지만 앱 재실행 시 초기화됩니다.
PNG 캐릭터는 보유한 대표 표정으로 표시합니다.
감정 판단 근거 창의 최근 영향 요인은 보관 중인 최대 30개 기록을 스크롤해 볼 수 있습니다.
최근 영향 요인 옆의 **일시정지**는 해당 목록만 고정하며 현재 감정·그래프·기타 정보와 기록은 계속 갱신됩니다.
**일시정지 해제**를 누르면 목록에 그동안 쌓인 최신 영향 요인을 반영합니다.

## 음성으로 캐릭터와 대화

**설정 → 사용자 인식**에서 마이크와 STT 옵션을 확인하고, 사용자 인식 콘솔에서
음성 인식을 시작하세요. 최종 인식된 문장은 텍스트 대화와 같은 입력으로 처리합니다.
사용자 발화를 먼저 표시하고 AI 답변을 말풍선으로 보여주며,
**설정 → 음성 → AI 답변 음성으로 읽기**에 따라 답변을 읽습니다.
AI API 키·모델과 Google 음성인식에 필요한 인터넷 연결을 사용합니다.

대화 중 추가로 받은 입력은 받은 순서대로 처리합니다. 현재 답변의 표시 시간과
음성 합성·재생이 끝난 뒤 다음 입력을 처리하며, 자동 대사가 대화를 덮어쓰지 않습니다.
같은 인식 이벤트는 한 번만 처리하고, 같은 말을 새로 한 경우에는 새 대화로 받습니다.
캐릭터가 말하는 동안의 녹음과 겹친 인식 결과는 제외하고, 재생 종료 후 짧게 잔향을 차단합니다.
요청이 실패하면 해당 입력을 보관하며 우클릭 메뉴의 **실패한 대화 다시 보내기**로 재시도할 수 있습니다.

## 말풍선 모양 선택

**설정 → 캐릭터 → 말풍선 UI**에서 **기존형 / 둥근 말풍선형 / 간결한 자막형**을
선택하세요. 캐릭터 탭을 아래로 스크롤하면 선택 항목과 미리보기가 나옵니다.
**적용** 또는 **저장 후 닫기**로 현재 말풍선에 반영하고 다음 실행에도 유지합니다.
대화 내용·음성 출력·남은 표시 시간은 유지하며, 긴 문장은 말풍선 안에서 스크롤해 읽을 수 있습니다.
말풍선은 캐릭터 이동을 따라가고 화면 경계와 게임 표시 위치를 고려해 배치합니다.

## 캐릭터 위 가위바위보

카메라를 켠 뒤 캐릭터를 우클릭해 **가위바위보 하기**를 선택하세요.
캐릭터 위에 **3 → 2 → 1** 카운트다운이 나타납니다. 카운트다운이 끝나면
한 손으로 가위·바위·보를 잠시 유지하세요. 캐릭터가 낸 손을 공개한 뒤
**사용자 기준 승리·패배·무승부**를 표시합니다.
카운트다운 전에 보인 손이나 이전 판의 인식 결과는 판정에 사용하지 않습니다.
손을 인식하지 못하면 재시도를 안내하며, **가위바위보 다시 하기 / 가위바위보 종료**는
캐릭터 우클릭 메뉴에서 조작합니다. 게임을 마치면 임시 게임 인식 모드를 해제합니다.

## 점프와 중력

준비된 점프 모션을 실제 상승·정점·하강·착지에 맞춰 재생합니다.
창에서 벗어나거나 드래그를 놓으면 중력으로 떨어지고, 위에서 아래로 창 윗면을
통과할 때 착지합니다. 감정이나 표시 표정을 바꿔도 진행 중인 비행 동작은 유지합니다.
중력은 경과시간으로 계산하며, 바닥은 작업표시줄을 포함한 전체 화면 아래쪽입니다.
실제 화면 원점·해상도·배율을 반영하고 사용자 정의 활동 범위는 실제 화면 안으로 제한합니다.
QHD는 특정 사용자의 검증 환경이며 앱의 고정 해상도가 아닙니다.

## 외부 감정·동작 인식 연결

`medeapipe_capstone` 또는 외부 모델의 인식 결과는 로컬 TCP JSON 브리지를 통해
캐릭터에 전달할 수 있습니다. 이벤트 형식과 실행 방법은
[`perception/README.md`](perception/README.md)를 참고하세요.

카메라가 실행 중일 때 손을 좌우로 흔들면 캐릭터가 손을 흔들고 “안녕! 👋” 말풍선을 표시합니다.
마이크나 STT 없이 손동작만으로 인사할 수 있습니다. **상시 인식**을 켜면
인식 콘솔에서도 손 흔들기 상태를 확인할 수 있습니다.
같은 인식 결과로 인사를 반복하지 않고 다음 인사까지 6초의 간격을 둡니다.
로그의 **사용자 인식** 탭에 손 흔들기 감지, 인사 재생·보류·반복 방지 여부가 표시됩니다.
잡고 있거나 점프·낙하·착지 중이면 동작이 끝난 뒤 인사합니다.
10초 안에 인사할 수 없는 경우에는 보류한 인사를 취소합니다.
손 흔들기는 기본 네이티브 리깅 렌더러의 인사 애니메이션을 사용하며,
인사 이미지가 없는 PNG 렌더러에서는 말풍선만 표시합니다.

자동 테스트는 개발 의존성을 설치한 뒤 실행합니다.

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
```
