# 캐릭터 상호작용 메뉴

캐릭터 몸을 **왼쪽 더블클릭**한 뒤 버튼에서 손을 떼면, 캐릭터 위에 네 가지 아이콘이 나타납니다.

| 아이콘 | 실행 | 상태에 따른 표시 |
| --- | --- | --- |
| 대화 | 대화 입력창 열기 | 이미 열려 있으면 작성 중인 내용을 유지하고 앞으로 가져옵니다. |
| 참참참 | 참참참 시작 | 진행 중에는 끝내기, 최종 결과·오류 화면에서는 다시 하기로 바뀝니다. 공중에서는 착지 후 시작할 수 있습니다. |
| 가위바위보 | 가위바위보 시작 | 진행 중에는 끝내기, 결과·오류 화면에서는 다시 하기로 바뀝니다. |
| 공 | 공 꺼내기 | 공이 있으면 치우기로 바뀝니다. |

아이콘을 한 번 클릭하면 메뉴가 닫히고 선택한 기능이 실행됩니다. **바깥 클릭, Esc, 캐릭터 다시 더블클릭**으로도 닫습니다. 방향키로 아이콘을 이동하고 Enter 또는 Space로 선택할 수 있습니다. 시간 경과로 자동으로 닫지는 않습니다.

메뉴는 실제 캐릭터 머리 위에 붙으며, 위쪽 공간이 부족하면 아래쪽으로 이동합니다. 화면 가장자리에서는 화면 안으로 조정하고, 말풍선과 게임 안내창을 피합니다. 메뉴가 열린 동안 자동 이동과 손으로 다시 잡기는 멈추지만 감정 갱신은 계속됩니다.

한 번 클릭은 더블클릭 판정 시간이 지난 뒤 기존 클릭 반응으로 처리합니다. 누른 상태로 마우스를 일정 거리 이상 움직이면 판정 시간을 기다리지 않고 드래그를 시작합니다. 더블클릭으로 메뉴를 여는 동작은 클릭 감정이나 아이템 사용으로 중복 처리하지 않습니다.

**우클릭**과 Shift+F10에는 로그, 설정, 사용자 인식 콘솔, 감정 판단 근거 같은 관리 기능을 둡니다. 실패한 대화가 있으면 기존 다시 보내기도 유지합니다. 공 단축키 Ctrl+Shift+B도 계속 사용할 수 있습니다.
